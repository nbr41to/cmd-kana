# cmd-kana 0.10.1

## 変更点

- 設定画面のバージョン表示の右側に「ダウンロード元（GitHub）」ボタンを追加しました。
- メニューバーの「更新を確認…」の下にも、同じダウンロード元への項目を追加しました。
- どちらからも既定のブラウザでGitHub Releasesの最新版ページを開けます。ブラウザを開けない場合は、URLを表示します。

## ダウンロード・更新

「Assets」の `cmd-kana-0.10.1-macos.zip` を展開し、cmd-kanaを終了してから「アプリケーション」内の`cmd-kana.app`を入れ替えてください。0.10.0からは、アプリ内の「更新を確認…」も利用できます。

**Developer ID未署名・Apple未公証の無料配布版です。** 整合性を確認するアドホック署名はありますが、Appleによる開発元の確認は受けていません。初回起動時に警告が出る場合は、一度起動を試みた後、「システム設定 → プライバシーとセキュリティ」のcmd-kanaの項目から「このまま開く」を選び、確認に従ってください。macOS 11・12では「システム環境設定 → セキュリティとプライバシー」を確認します。

「Assets」のチェックサムを同じフォルダに保存すると、整合性を確認できます。

```sh
shasum -a 256 -c cmd-kana-0.10.1-macos.zip.sha256
```

## 対応環境と確認範囲

Apple Silicon Mac（arm64）、macOS 11.0以降、USキーボード向けです。ログイン時の自動起動にはmacOS 13以降が必要です。

CIでビルド・テストと配布ZIPの検証を行います。ブラウザへの遷移や各IME・入力欄での実機操作は自動テストとは別の確認項目で、すべての組み合わせでの手動確認結果は記録されていません。

不具合は [Issues](https://github.com/nbr41to/cmd-kana/issues) に、利用環境と再現手順を添えて報告してください。個人情報や私的な入力内容は含めないでください。
