# cmd-kana 0.10.3

## 変更点

- 未確定入力中にカーソルを動かしたり文字を選択したりしたときは、左⌘2回押し用の入力履歴を破棄し、入力確定などの区切りから記録を再開します。
- アクセシビリティAPIで置換するIMEでは、選択範囲が残っている場合や入力欄が置換に対応していない場合、削除キーの自動送信をやめ、英数への切り替えだけを行います。

## ダウンロード・更新

「Assets」の `cmd-kana-0.10.3-macos.zip` を展開し、cmd-kanaを終了してから「アプリケーション」内の `cmd-kana.app` を入れ替えてください。0.10.0以降からはアプリ内の「更新を確認…」も利用できます。

**Developer ID未署名・Apple未公証の無料配布版です。** 配布アプリには整合性確認用のアドホック署名があります。初回起動がブロックされた場合は、一度起動を試みたあと、「システム設定 → プライバシーとセキュリティ」でcmd-kanaの「このまま開く」を選んでください。macOS 11・12では「システム環境設定 → セキュリティとプライバシー」を開きます。

ZIPとチェックサムを同じフォルダに保存すると、次のコマンドで整合性を確認できます。

```sh
shasum -a 256 -c cmd-kana-0.10.3-macos.zip.sha256
```

## 対応環境と確認範囲

Apple Silicon Mac（arm64）、macOS 11.0以降、USキーボード向けです。ログイン時の自動起動にはmacOS 13以降が必要です。

CIでは入力判定のテストとmacOS配布ZIPの検証を行います。macOS実機での各IME・入力欄の手動確認は未実施です。
