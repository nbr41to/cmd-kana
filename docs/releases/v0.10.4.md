# cmd-kana 0.10.4

## 変更点

- 右⌘を1回押すと、macOSのAPIで日本語入力ソースを直接選びます。仮想「かな」キーの送信を廃止し、IMEが切り替え操作を再変換として扱う経路をなくしました。
- 左⌘の2回押しでアクセシビリティAPIを使う場合は、カーソル直前の文字列と、入力欄が実際に選んだ範囲を照合してから置換します。たとえば `tte` の置換対象は `って` の2文字だけです。表示や選択範囲が想定と異なる場合は置換を中止します。

## ダウンロード・更新

「Assets」の `cmd-kana-0.10.4-macos.zip` を展開し、cmd-kanaを終了してから「アプリケーション」内の `cmd-kana.app` を入れ替えてください。0.10.0以降は、アプリ内の「更新を確認…」からも更新できます。

**Developer ID未署名・Apple未公証の無料配布版です。** 配布アプリには整合性確認用のアドホック署名があります。初回起動がブロックされた場合は、一度起動を試してから「システム設定 → プライバシーとセキュリティ」でcmd-kanaの「このまま開く」を選んでください。macOS 11・12では「システム環境設定 → セキュリティとプライバシー」を開きます。

ZIPとチェックサムを同じフォルダに保存すると、次のコマンドで整合性を確認できます。

```sh
shasum -a 256 -c cmd-kana-0.10.4-macos.zip.sha256
```

## 対応環境と確認範囲

Apple Silicon Mac（arm64）、macOS 11.0以降、USキーボード向けです。ログイン時の自動起動にはmacOS 13以降が必要です。

右⌘を1回押した後の `tte` 入力は、イベントの模擬テストとLinux版Mozcで確認しました。macOS実機での各IME・入力欄の手動確認は未実施です。
