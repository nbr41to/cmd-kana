# cmd-kana 0.10.0

USキーボードの左右Commandキーで、英数・かなを切り替えるmacOSアプリです。無料で利用できます。

## このバージョンの変更点

- GitHub Releasesの最新版を確認し、アプリ内でダウンロード・検証・入れ替え・再起動できるようになりました。
- 更新先のアプリの起動を確認するまで旧版を保持し、入れ替えや起動に失敗した場合は復旧を試みます。
- 以前の「更新」メニューを「再起動」に改名し、最新版のダウンロードと区別しました。
- READMEにダウンロード方法、初回設定、利用条件、プライバシー、アンインストール手順をまとめました。

## 対応環境

- Apple Silicon Mac（arm64）
- macOS 11.0以降
- USキーボード、英語・日本語の入力ソース

ログイン時の自動起動にはmacOS 13以降が必要です。Intel MacとJISキーボードはサポート対象外です。

## ダウンロードと初回設定

「Assets」の `cmd-kana-0.10.0-macos.zip` をダウンロードして展開し、`cmd-kana.app`を「アプリケーション」へ移動して起動してください。「Source code」はアプリの配布ZIPではありません。

**この配布版はDeveloper ID未署名・Apple未公証です。** アプリの整合性を確認するためのアドホック署名はありますが、Appleによる開発元の確認は受けていません。Apple Developer Programの加入や利用者のアカウント登録は不要です。

初回起動で開発元を確認できない旨の警告が出た場合は、一度起動を試みた後、「システム設定 → プライバシーとセキュリティ」のcmd-kanaの項目から「このまま開く」を選び、確認に従ってください。macOS 11・12では「システム環境設定 → セキュリティとプライバシー」を確認します。Mac全体のセキュリティ機能を無効にする必要はありません。

初回起動後、「システム設定 → プライバシーとセキュリティ」で「入力監視」と「アクセシビリティ」を許可してください。

配布ZIPと同じフォルダに `.sha256` ファイルを保存すると、ターミナルから整合性を確認できます。

```sh
shasum -a 256 -c cmd-kana-0.10.0-macos.zip.sha256
```

配布ZIPは、CIでビルド、テスト、コード署名の整合性、バージョン、対応CPU、最低対応OS、チェックサムを確認してから公開します。Apple公証済みであることを意味しません。

## 既存の版からの更新

「更新を確認…」がない旧版では、cmd-kanaを終了してから「アプリケーション」内のアプリを入れ替えてください。更新機能を含む版からは、設定画面またはメニューバーの「更新を確認…」を利用できます。

署名の条件が変わるソースビルド版などからの移行では、macOSの権限を再設定する必要がある場合があります。

## プライバシーと既知の制限

入力内容やキー履歴を外部へ送信しません。ネットワーク通信は、利用者が選択した更新確認とダウンロードに使います。

IMEや入力欄によって、2回押し変換の結果が異なる場合があります。Google日本語入力・MozcではIME標準の英数2回押しを利用します。その他のIMEでは、Delete後、記録上限を超えた入力、Shift依存の入力などで推測による置換を行いません。

CIによる自動検証に加え、Macの各IME・入力欄・権限設定・アプリ内アップデートの手動確認は継続して行う項目です。すべての組み合わせでの実機確認結果は記録されていません。

不具合は [Issues](https://github.com/nbr41to/cmd-kana/issues) に、バージョン・利用環境・再現手順を添えて報告してください。個人情報や私的な入力内容は含めないでください。
