# cmd-kana 0.10.5

## 変更点

- macOSの入力メニューが日本語を表示しているのに、入力欄では英数のままになる場合に、右⌘で日本語入力へ復帰できるようにしました。
- その復帰処理で使う仮想「かな」キーには550ミリ秒の間隔を設けています。クリックや文字選択を挟んでも間隔の判定を続け、連続した「かな」が再変換を起こすのを防ぎます。

## ダウンロード・更新

「Assets」の `cmd-kana-0.10.5-macos.zip` を展開し、cmd-kanaを終了してから「アプリケーション」内の `cmd-kana.app` を入れ替えてください。0.10.0以降はアプリ内の「更新を確認…」からも更新できます。

**Developer ID未署名・Apple未公証の無料配布版です。** 配布アプリには整合性確認用のアドホック署名があります。初回起動がブロックされた場合は、一度起動を試してから「システム設定 → プライバシーとセキュリティ」でcmd-kanaの「このまま開く」を選んでください。macOS 11・12では「システム環境設定 → セキュリティとプライバシー」を開きます。

ZIPとチェックサムを同じフォルダに保存すると、次のコマンドで整合性を確認できます。

```sh
shasum -a 256 -c cmd-kana-0.10.5-macos.zip.sha256
```

## 対応環境と確認範囲

Apple Silicon Mac（arm64）、macOS 11.0以降、USキーボード向けです。ログイン時の自動起動にはmacOS 13以降が必要です。

メニューバーとIMEの状態がずれた場合のイベント送信と、連続した「かな」を抑止する条件は模擬テストで確認しました。macOS実機でのIME操作は未確認です。
