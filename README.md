## cmd-kanaとは

cmd-kanaは、JISキーボードの「英数」「かな」に近い操作をUSキーボードで実現する、小さなメニューバー常駐アプリです。

左右のCommandキーを単独で押したときだけ入力モードを切り替えるため、`⌘C`、`⌘V`など通常のショートカットはそのまま使用できます。Google日本語入力を含め、直前に使用していた英数・日本語入力モードへ戻ります。

無料のオープンソースソフトウェアとして提供しています。ユーザー登録やサブスクリプションは不要で、個人・法人、商用・非商用を問わず利用できます。

### 主な機能

| 操作 | 動作 |
| --- | --- |
| 左Commandを単独で押して離す | 最後に使った英数入力へ切り替え |
| 右Commandを単独で押して離す | 最後に使った日本語入力へ切り替え |
| 左Commandを550ms以内に2回 | 直前に入力した1語を英数表記へ変換 |
| Commandと別のキーを同時に押す | 通常のCommandショートカットとして動作 |

例えば、日本語入力中に`こんにちは`と入力して左Commandを素早く2回押すと、カーソル位置を大きく動かさずに`konnnitiha`へ置き換えます。右Commandの2回押し変換はありません。

そのほか、次の機能を備えています。

- メニューバーへの表示・非表示
- 入力監視とアクセシビリティの状態確認
- 権限付与後の入力監視自動復旧
- ログイン時の自動起動（macOS 13以降）
- 重複起動の防止
- GitHub Releasesでの更新確認・ダウンロード・アプリの入れ替えと再起動
- 権限トラブル時の再設定ガイド

## 動作環境

- Apple Silicon Mac（arm64）
- macOS 11.0以降
- USキーボード
- macOSの入力ソースに英語と日本語が追加されていること

「ログイン時に起動する」の設定にはmacOS 13.0以降が必要です。Intel MacとJISキーボードは現在のサポート対象外です。

## ダウンロードとインストール

公式の配布先は、このリポジトリの[GitHub Releases](https://github.com/nbr41to/cmd-kana/releases)です。公開されたバージョンの変更点は[変更履歴](CHANGELOG.md)から確認できます。

> **配布状況：正式版の公開準備中**
>
> 現在、GitHub Releasesにダウンロード用の正式版は公開されていません。Developer ID署名・Apple公証済みアプリの公開までは、下記の手順でソースからビルドしてください。GitHub Actionsのテスト用成果物は、一般配布版ではありません。

次の配布候補は **0.10.0** です。[リリースノート案](docs/releases/v0.10.0.md)と[公開前の確認状況](docs/releases/v0.10.0-checklist.md)を参照できます。

### 配布版をインストールする（正式版の公開後）

1. [Releases](https://github.com/nbr41to/cmd-kana/releases)で最新版のリリースノートと対応環境を確認します。
2. 「Assets」からアプリの配布用ZIP（`cmd-kana-<バージョン>-macos-notarized.zip`）をダウンロードします。「Source code」はソース一式のため、そのまま起動することはできません。
3. ZIPを展開し、`cmd-kana.app`を「アプリケーション」フォルダへ移動します。
4. 「アプリケーション」からcmd-kanaを起動し、[初回設定](#初回設定)へ進みます。

配布版の利用にRustやXcodeは不要です。ダウンロードフォルダやZIP内からではなく、「アプリケーション」に移動してから起動してください。

### ソースからビルドする

ビルドには、Apple Silicon Macと次の開発ツールが必要です。

- Xcode Command Line Tools
- [Rust公式のrustup](https://rust-lang.org/tools/install/)

```sh
xcode-select --install
```

ツールの準備後、ソースを取得してアプリを作成します。

```sh
git clone https://github.com/nbr41to/cmd-kana.git
cd cmd-kana
./scripts/package.sh
```

アプリは`target/release/cmd-kana.app`へ作成されます。通常利用では`/Applications`へコピーして起動してください。

すでにcmd-kanaを利用している場合は、設定画面の「アプリを終了」またはメニューの「閉じる」から終了してからコピーしてください。

```sh
ditto target/release/cmd-kana.app /Applications/cmd-kana.app
open /Applications/cmd-kana.app
```

## 初回設定

cmd-kanaを起動すると設定画面が開きます。「システム設定 → プライバシーとセキュリティ」で、次の2つを許可してください。

| 権限 | 使用目的 |
| --- | --- |
| 入力監視 | Commandキーと、2回押し変換に必要な直前の物理キー列を検出するため |
| アクセシビリティ | 仮想の英数・かなキー送信と、カーソル直前の文字列置換を行うため |

許可はいつでもシステム設定から解除できます。許可後はアプリを再起動しなくても、最大数秒で入力監視を自動的に開始します。

## 設定とメニューバー

通常起動では設定画面が開きます。ログイン項目として起動した場合は、ウィンドウを表示せず静かに常駐します。

設定画面では次の操作ができます。

- メニューバーに表示する
- ログイン時に起動する
- 権限状態を確認する
- 入力監視・アクセシビリティのシステム設定を開く
- 権限の再設定手順を確認する
- GitHub Releasesの最新版を確認し、ダウンロードして更新する
- アプリを再起動・終了する

メニューバーには、バージョン、設定を開く、更新を確認、再起動、閉じるを表示します。

メニューバーのアイコンを非表示にしている場合も、「アプリケーション」からcmd-kanaをもう一度開くと設定画面を表示できます。

## アップデート

更新機能を含む版では、次の手順でアプリ内から更新できます。

1. 設定画面またはメニューバーで「更新を確認…」を選びます。
2. 新版がある場合は、バージョンを確認して「ダウンロードして更新」を選びます。
3. ダウンロードとファイルの検証後、アプリを入れ替えて自動的に再起動します。

更新の確認は手動です。起動時やバックグラウンドで定期的に確認することはありません。GitHub Releasesの正式版を対象とし、リポジトリにソースが追加されただけでは更新として扱いません。配布版がまだない場合や通信に失敗した場合は、その理由を表示します。

更新には、アプリが置かれているフォルダへの書き込み権限が必要です。ダウンロードしたファイルの整合性とコード署名などを確認し、新しいアプリの起動を確認するまで旧版を保持します。入れ替えや起動に失敗した場合は旧版への復旧を試み、復旧できない場合はバックアップの場所を表示します。「再起動」は、現在インストールされているアプリを起動し直す操作です。

「更新を確認…」がない旧版を使っている場合は、最新版の配布ZIPを取得し、cmd-kanaを終了してから「アプリケーション」内のアプリを入れ替えてください。ソースからビルドした版は、利用するソースを更新して再ビルドすることもできます。

## アンインストール

1. 「ログイン時に起動する」を有効にしている場合は、設定画面でオフにします。
2. 設定画面の「アプリを終了」またはメニューの「閉じる」からcmd-kanaを終了します。
3. 「アプリケーション」内の`cmd-kana.app`をゴミ箱へ移動します。
4. 必要に応じて、「システム設定 → プライバシーとセキュリティ」の「入力監視」「アクセシビリティ」からcmd-kanaの許可を解除し、項目を削除します。

アプリを削除しても、macOSに保存された設定や権限の履歴が残る場合があります。

## プライバシー

cmd-kanaは、入力切り替えと文字列の置換に必要な範囲でキーボードイベントを扱います。入力内容を外部へ送信したり、キー履歴をディスクへ保存したりすることはありません。

2回押し変換のために記録する直前の物理キー列は、メモリ上だけに保持します。空白、改行、クリック、ショートカットなどの区切りで破棄します。

ネットワーク通信は、「更新を確認…」を選んだときの更新情報の取得と、更新を承認した後の配布ファイルのダウンロードに使用します。その際、GitHubおよび配信先にはIPアドレスなどの接続情報が伝わりますが、入力内容やキー履歴は送信しません。詳細は[セキュリティポリシー](SECURITY.md)を参照してください。

## 仕組み

単押し切り替えでは入力ソースを直接書き換えず、macOS標準の仮想「英数」「かな」キーを送信します。そのため、macOS標準IMEやGoogle日本語入力が持つ直前のモードを利用できます。

Google日本語入力とMozcでは、左Commandの2回押しをIME標準の英数2回押しへ渡します。未確定文字と元のキー列をIME自身が扱うため、アプリ側で未確定文字をDeleteしたり、表示文字数を推測して置換したりしません。

その他のIMEでは、直前に連続入力された物理キー列を最大128キーまでメモリに記録します。Deleteによる編集後と128キーを超えた入力では、置換範囲を誤らないよう変換を取り消します。空白・改行などの境界、または右Commandによるかなへの切り替えで記録を再開します。対応する入力欄ではアクセシビリティAPIでカーソル直前をローマ字へ直接置換し、対応しない入力欄のみDeleteと再入力へフォールバックします。Shiftを含む入力ではIME設定によって表示が変わるため、推測による置換を行いません。

入力イベントの判定とローマ字変換はテスト可能なRustコードへ分離し、macOSのUIとアクセシビリティ連携だけを小さなObjective-Cブリッジにまとめています。外部Rustクレートには依存していません。

## トラブルシューティング

### Commandキーを押しても切り替わらない

1. 設定画面で入力監視とアクセシビリティが「許可済み」になっているか確認します。
2. 「動かない場合」を押して再設定手順を開きます。
3. 許可済みでも動かない場合は、システム設定の一覧からcmd-kanaを一度削除します。
4. `/Applications/cmd-kana.app`を追加し直し、両方をオンにします。

権限が反映されると入力監視は自動的に再開します。

### Google日本語入力ではなくmacOS標準の英数になる

左CommandはmacOSの仮想「英数」キーを送信します。先にGoogle日本語入力の英数モードを一度選択してから切り替えると、以後はそのモードへ戻ります。

### 2回押し変換が意図しない範囲へ作用する

2回押しの対象は、空白、改行、クリック、Command・Control・Optionショートカットの後にリセットされます。再現する場合は、macOSのバージョン、IME、利用アプリ、入力例を添えてIssueで報告してください。個人的な入力内容は含めないでください。

### ダウンロードや更新ができない

まず[Releases](https://github.com/nbr41to/cmd-kana/releases)に配布版が公開されているか確認してください。公開前は、アプリ内の更新確認でも「配布版はまだ公開されていません」と表示します。

通信エラーやアクセス制限が表示される場合は、接続を確認して時間を置いてから再試行してください。アプリの入れ替えができない場合は、書き込み可能な「アプリケーション」フォルダへ移動してから試してください。
